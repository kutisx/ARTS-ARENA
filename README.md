## Краткое описание проекта

ARTS ARENA — сайт фестиваля современного цифрового искусства. Проект включает три страницы:

- `index.html` — главная: представление художников, блоки-ссылки на UV-выставку, локации и билеты.
- `page2.html` — UV-выставка: описание, слайдер инсталляций, встроенное видео.
- `page3.html` — покупка билетов: выбор уровня (Стандарт, Премиум, Мастер), календарь для выбора дат, расчёт стоимости, модальное окно подтверждения.

Дизайн выполнен в тёмной стилистике с неоновыми акцентами (розовый, лаймовый, серый). Вёрстка использует единицы `vw` для адаптивности. На странице билетов подключён Bootstrap 5 через CDN.

## Как запустить

1. Склонируйте репозиторий или скачайте файлы, сохранив структуру:
   ├── index.html
├── page2.html
├── page3.html
├── css/
│ ├── style.css
│ ├── style2.css
│ └── style3.css
├── js/
│ ├── script.js
│ ├── scriptUV.js
│ └── scriptBL.js
├── img/
│ └── ... (изображения и иконки)
└── fonts/
└── Stezhok.otf

2. Откройте `index.html` в браузере.

3. Для корректной работы iframe с YouTube рекомендуется запустить локальный сервер:
- **VS Code + Live Server**: установите расширение, нажмите правой кнопкой на `index.html` → «Open with Live Server».
- **Python**: `python -m http.server 8000` и откройте `http://localhost:8000`.
- **Node.js**: `npx serve`.

Приятного просмотра!
